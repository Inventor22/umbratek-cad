# umbratek-cad
This repository contains Solidworks CAD models for the Umbratek Utra 1000 robotic arm.

![The UTRA 6-1000 arm on its cart](Renders/Utra%201000%20Assembly%20Render%201.JPG)

The arm stands on a cart of 80/20 aluminum extrusion. A braced column holds the arm's base 730 mm above the floor,
and the NTRO controller sits on a plank at its foot.
