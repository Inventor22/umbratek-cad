# umbratek-cad
This repository contains Solidworks CAD models for the Umbratek Utra 1000 robotic arm.

The [pen holder end effector](End%20Effectors/Pen%20Holder/README.md) is a parametric build123d model (Python) with STEP/STL exports. A [quick-change variant](End%20Effectors/Quick-Change%20Pen%20Holder/README.md) mounts the pen perpendicular to the flange, takes any pen from 6 to 17 mm, and swaps pens without tools. Version 2 of each ([coaxial](End%20Effectors/Pen%20Holder%20v2/README.md), [quick-change](End%20Effectors/Quick-Change%20Pen%20Holder%20v2/README.md)) replaces the coil springs with a printed PETG flexure. The leaf-spring versions ([coaxial](End%20Effectors/Pen%20Holder%20v2%20Leaf%20Spring/README.md), [quick-change](End%20Effectors/Quick-Change%20Pen%20Holder%20v2%20Leaf%20Spring/README.md)) keep v1's sliding guides and swap only the springs for printed PETG bow-spring stacks.

The [chess gripper](End%20Effectors/Chess%20Gripper/README.md) has an animation of how it works: one SG90 servo pushes three claws open, and a broccoli rubber band closes them and holds the piece.
