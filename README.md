# umbratek-cad
This repository contains Solidworks CAD models for the Umbratek Utra 1000 robotic arm.

The [pen holder end effector](End%20Effectors/Pen%20Holder/README.md) is a parametric build123d model (Python) with STEP/STL exports. A [quick-change variant](End%20Effectors/Quick-Change%20Pen%20Holder/README.md) mounts the pen perpendicular to the flange, takes any pen from 6 to 17 mm, and swaps pens without tools.

The [chess gripper](End%20Effectors/Chess%20Gripper/README.md) has an animation of how it works: one SG90 servo pushes three claws open, and a broccoli rubber band closes them and holds the piece.

A few models were not designed by me:

Utra 1000 robotic arm: https://www.umbratek.com/download-center

Toaster: https://grabcad.com/library/toaster--1

Chess set: https://grabcad.com/library/chess-set-35
